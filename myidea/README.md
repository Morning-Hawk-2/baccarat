# baccarat

公開URL: https://baccarat.asatakasakuda.workers.dev

バカラディーラー研修シミュレーター

## 何を作るか

バカラのディーラー業務のうち、第三カードルールの判定・勝敗判定・配当計算という「判断・計算」の部分を、仮想テーブル上のクイズ形式で練習できる、ブラウザ完結のトレーニングシミュレーター。ベット受付・カード配布・支払いはシステムが自動演出し、研修生は判断・計算のステップだけに回答する。

## 誰が使うか

バカラ未経験の新人ディーラー研修生(カジノ等の登用・新人研修中の受講者)。

## できること

1. 仮想テーブルで「次のハンドへ」を押すと、ベット受付→カード配布→支払いが自動で進行する画面が表示される
2. Player/Bankerの初手カードを見て、第三カードのDraw/Standをボタンで回答すると、その場で正解/不正解と根拠が一行表示される
3. 配られたカードを見て勝敗(Player win / Banker win / Tie)をボタンで回答すると、その場で正解/不正解が表示される
4. そのハンドで置かれたベット(Player/Banker/Tie/Player Pair/Banker Pairのいずれか)の配当額を4択から回答すると、その場で正解/不正解が表示される
5. 画面の成績パネルに、項目別(Player Draw/Stand・Banker Draw/Stand・勝敗判定・配当計算)と全体の正答率がその場で累積表示され、確認ダイアログ付きのリセットボタンでいつでも0に戻せる

## 今回やらないこと

- ログイン・成績保存・研修担当者向け閲覧機能 — バックエンドを持たない個人練習用ツールに限定するため
- シュー残数・リシャッフル管理などの複数デッキ運用 — 1ハンド完結・毎回新規配布という前提でスコープ外のため
- チップのドラッグ&ドロップ操作やカード配布そのものの手技練習 — 判断・計算スキルの練習に対象を絞るため
- Player Pair / Banker Pair以外のサイドベット(Perfect Pair、Big/Smallなど) — v1で扱うベット種別を主要3種+Pair2種に限定するため
- 日本語以外のUI言語対応 — 対象ユーザーが日本語話者の研修生であるため

## 完成判定

- 「次のハンドへ」を押すたびに、ベット受付→カード配布→(Draw/Stand回答)→勝敗回答→配当計算回答→支払いの一連の流れが途切れず繰り出される
- 各回答の直後に正解/不正解と根拠が表示され、成績パネルの項目別・全体の正答率が更新され続ける
- 意図的に誤答しても、カードの配布・最終的な勝敗・配当は常に正しいバカラルールに従って進行する(研修生の回答は採点のみに使われ、進行は分岐しない)
- モバイル幅のブラウザでもレイアウトが崩れず操作できる
